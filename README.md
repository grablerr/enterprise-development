# Лабораторная работа 1: Классы - Реализация объектной модели данных и unit-тестов
## Описание предметной области

Реализована объектная модель для риэлторского агентства, включающая три основных сущности:

- **Объекты недвижимости** (`RealEstate`) - 10 экземпляров различных типов (квартиры, дома, офисы, склады и др.)
- **Контрагенты** (`Counterparty`) - 5 клиентов с полными идентификационными данными  
- **Заявки** (`Application`) - 10 транзакций на покупку и продажу недвижимости

## Выполненные задачи

### 1. Модель данных
Создана полная объектная модель с использованием enum-типов:
- `ObjectType` - типы недвижиости (квартира, дом, офис и т.д.)
- `ObjectPurpose` - назначение объектов (квартира, дом, офис и т.д.)
- `ApplicationType` - тип операций (покупка, продажа)

### 2. Тестовые данные
Подготовлен комплексный класс `FixtureDataClass` содержащий:
- 10 объектов недвижимости
- 5 контрагентов 
- 10 заявок на покупку\продажу недвижимости

### 3. Unit-тесты
Реализованы все требуемые бизнес-запросы с использованием LINQ:

- **`GetSellersByPeriod`** - вывод всех продавцов, оставивших заявки за заданный период
- **`GetTop5ClientsByRequests`** - вывод топ 5 клиентов по количеству заявок (отдельно на покупку и продажу)
- **`GetRequestCountByObjectType`** - вывод информацию о количестве заявок по каждому типу недвижимости
- **`GetClientsWithMinPriceRequests`** - вывод информацию о клиентах, открывших заявки с минимальной стоимостью
- **`GetClientsByEstateType`** - вывод сведений о всех клиентах, ищущих недвижимость заданного типа, упорядоченных по ФИО

## Результат

Создана объектная модель предметной области с комплексными unit-тестами, покрывающими все бизнес-требования задания. Тесты демонстрируют работу с реальными данными и проверяют корректность бизнес-логики обработки заявок в риэлторском агентстве.
